# Large-caliber turret

"large-caliber turret" by stasbelyk13
(https://sketchfab.com/3d-models/large-caliber-turret-d62842657df7495b948778d92044c3fe),
licensed under CC Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/). The creator marks it NoAI:
it may not be used in datasets for, or as input to, generative AI.

Changed for this project by `Tools/Art/prepare_turret.py`: scaled to half size, bones renamed (Base, Yaw, Pitch),
aim constraints and demo animation removed, a Muzzle point added, textures resized to 2048 px, the normal map
converted from DirectX to OpenGL and metallic/roughness packed into an HDRP mask map.
