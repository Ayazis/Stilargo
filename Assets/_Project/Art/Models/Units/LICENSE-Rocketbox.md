# Microsoft Rocketbox avatars

Military_Male_01, Military_Male_02, Military_Male_03 and Military_Female_01 come from
https://github.com/microsoft/Microsoft-Rocketbox (MIT License, Copyright (c) Microsoft Corporation).

Changed for this project: TGA textures converted to PNG; specular maps repacked as HDRP mask maps
(smoothness = specular grey x 0.6, metallic 0, AO 1). Facial-rig FBX files and legacy shaders were left out.
